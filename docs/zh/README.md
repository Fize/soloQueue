# SoloQueue 中文文档

[English documentation hub](../README.md) · [English README](../../README.md)

我使用 SoloQueue 作为本地优先的个人 AI Agent Harness 与多智能体工作台。
我在 Harness Engineering 学习实践中参考了 OpenClaw，并逐渐把 SoloQueue
变成了我日常使用的完整软件。

我把这套中文文档提供给希望使用、配置和理解 SoloQueue 的读者。每篇中文文档都
链接对应的英文版本；我也在英文版本中链接回中文文档。
